### [1. ธีมและสไตล์ภาพ (Retro Cyberpunk Hacker Terminal)]
- คอนเซปต์: หน้าจอคอมพิวเตอร์ของ Hacker/สืบสวนคดีไซเบอร์ในยุค 90s ผสมอนาคต (Retro-Futuristic Terminal)
- สีหลัก: ดำ (#0D1117), เขียวมอนิเตอร์เก่า (#00FF66), และ ส้มสปาย/แจ้งเตือน (#FF9900)
- รูปแบบฟอนต์: Monospace (เช่น JetBrains Mono, Courier New)
- Visual Effects: 
  * CRT Screen Scanlines & flickering subtle effect
  * แฟลชสีแดงสั้นๆ เมื่อพิมพ์คำตอบผิด หรือเสียง/กราฟิกเตือนภัย
  * โต้ตอบด้วย Terminal CLI (Command Line Interface) จำลอง ผสมผสานกับ Visual Code Block UI ด้านข้างเพื่อให้เด็ก ม.ต้น เล่นง่าย ไม่ยากเกินไป
  * มี "กล่อง Dossier (แฟ้มประวัติภารกิจ)" และ "ระบบแผงวงจร/แผนที่เครือข่าย" วาดด้วย SVG เพื่อสร้างบรรยากาศ

### [2. โครงสร้างหน้าจอ (Screen Layout - Flex/Grid แบบ Full Responsive)]
แบ่งจอออกเป็น 3 ส่วนหลัก (3-Panel Interface):
1. ซ้าย (The Briefing / Mission Control):
   - ชื่อด่าน, ภารกิจ, แฟ้มลับ, บทสนทนากับหัวหน้า/AI Buddy (ตัวละครที่ช่วยบอกใบ้)
   - ข้อมูลดิบ/เบาะแส (เช่น Log file, รหัสลับที่ต้องแปลง, ข้อมูลเครือข่าย)
2. กลาง (The Cyber Workspace / Code Editor):
   - พื้นที่ใส่ "คำสั่ง" หรือ "สคริปต์สั้นๆ" มีตัวเลือกให้เด็กเลือกว่าจะใช้โหมด "พิมพ์โค้ด (CLI Python-Like)" หรือ "คลิกวางชิ้นส่วนโค้ด (Block-Like / Dropdown)" เพื่อให้เด็ก ม.ต้น ทุกระดับเล่นได้
   - มีเทมเพลตโค้ดสั้นๆ และช่องให้แก้พารามิเตอร์ หรือเขียน Logic เพิ่มเติม เช่น `for i in range(...):` หรือ `if line == ...:`
   - ปุ่มใหญ่ๆ: [RUN SCRIPT] / [INJECT EXPLOIT]
3. ขวา (Terminal Output & Matrix Map):
   - Terminal จำลองที่จะรันผลลัพธ์จากโค้ดของเด็ก บรรทัดต่อบรรทัดแบบ Real-time
   - ภาพกราฟิก SVG จำลองการทำงาน (เช่น แถบดาวน์โหลดข้อมูลที่ค่อยๆ เพิ่ม, แผนผังเซิร์ฟเวอร์ที่เปลี่ยนสถานะจาก ล็อค -> แฮกสำเร็จ)

### [3. ด่านและระบบ Logic Puzzles (3 Levels for Demo)]
สร้างภารกิจ 3 ด่านที่มีเนื้อเรื่องเชื่อมโยงกันอย่างเข้มข้น และมีระดับ Logic สำหรับ ม.ต้น:

💡 ด่านที่ 1: "The Decryptor" (ฝึกเรื่อง Indexing & String Slicing)
- เนื้อเรื่อง: "กู้ข้อมูลไฟล์ลับจากเซิร์ฟเวอร์ฝ่ายตรงข้ามที่กําลังถูกทำลาย" ตัวตรวจจับบอกว่า รหัสผ่านถูกซ่อนอยู่ในข้อมูล String ยาวๆ โดยเอามาเฉพาะตัวอักษรตำแหน่งที่กําหนด
- โจทย์: เด็กต้องตัดคำ (Slicing) เพื่อถอดรหัสลับ เช่น
  * String ข้อมูลดิบ: "XF7_P_A_S_S_W_O_R_D_Z2B"
  * โค้ดด่านแรก: `password = raw_data[4:12]` (ตัวอย่างใบ้) เด็กต้องคำนวณตำแหน่ง Index ให้ถูกต้องเพื่อเอาเฉพาะคำว่า "PASSWORD" หรือคำเฉพาะที่กำหนด (เช่น ตัวอักษรที่ 3, 5, 7, 9 เพื่อเป็นโค้ดยืนยัน)
- ระบบช่วยเหลือ: มีไม้บรรทัดบอกตำแหน่ง Index (0, 1, 2, 3...) อยู่เหนือข้อมูลดิบ เพื่อให้เด็กเข้าใจง่าย

💡 ด่านที่ 2: "The Intruder Hunt" (ฝึกเรื่อง Loops และ Conditions / Filter)
- เนื้อเรื่อง: "มีไอพีปลอมแปลงตัวเข้าสู่ระบบ ตรวจหาไอพีลึกลับที่เข้าใช้งานเกิน 10 ครั้งและเป็นไอพีจากประเทศนอกทวีป!"
- ข้อมูล: Array ของ Object ใน Log ประวัติ เช่น `[{ip: '192.168.1.5', login: 3, suspicious: false}, {ip: '10.99.12.3', login: 15, suspicious: true}, ...]`
- โจทย์: เด็กต้องเขียนโค้ด loop คัดกรอง log (หรือเติมช่องว่างใน loop `for` และ `if`) เพื่อหา IP ที่ต้องสงสัย
  * โค้ดตัวอย่าง:
    ```python
    suspected_ips = []
    for log in server_logs:
        if log.login > 10 and log.suspicious == True:
            suspected_ips.append(log.ip)
    ```
- ตัวช่วย: มี "เครื่องสแกน Visual" ที่จะสแกนประวัติทีละบรรทัดตามรอบ Loop ถ้าเจอบรรทัดที่เข้าข่าย จะเป็นไฟสีแดง และไอดีนั้นจะกระเด้งเข้าสู่อารีน่า!

💡 ด่านที่ 3: "Overclock Search" (ฝึกเรื่อง Binary Search / High-Low Logic)
- เนื้อเรื่อง: "หา Port หรือ Node เครือข่ายที่ซ่อนบอททำลายล้างไว้ในไอพี 1 ถึง 100 ภายใน 7 วินาที!" (หากค้นแบบเรียงทีละอันจะไม่ทัน ต้องใช้หลักการ Binary Search ย่อขนาดการหา)
- โจทย์: เด็กต้องป้อน/คลิกเลือกเป้าหมายที่จะสแกน (สแกนแบบ 1-100 หรือแบบ Binary search) ระบบจะบอกใบ้ว่า "Higher" หรือ "Lower" 
- เกมเพลย์: บีบคั้นด้วยเวลา มี Visual-meter แถบความร้อนพุ่งขึ้นเรื่อยๆ เด็กต้องเขียนเงื่อนไขเพื่อหา node ล็อคเป้าให้ไวที่สุด (หรือคลิกเลือก Binary code Logic ตัวอย่าง)

### [4. UX / UI & Feedback System ที่ต้องการ]
- Typing Effect: ให้ข้อความเนื้อเรื่องและ log terminal ค่อยๆ พิมพ์ขึ้นมาเหมือนคอมพิวเตอร์จริง
- Sound Effects (Optional/Visual): มีเอฟเฟ็กต์เสียง "Beep", "Access Granted", "Warning/Error" (ใช้เสียงสั้นๆ จาก Web Audio API ที่สร้างด้วยโค้ดเลย เพื่อประหยัดพื้นที่และทำงานได้ดีที่สุด หรือสั่นหน้าจอเล็กน้อยเมื่อ Error)
- การประเมินผล (Instant Feedback):
  - เมื่อเด็กกด "Run Code" -> Terminal จะต้องจำลองการประมวลผล เช่น "SCANNING PORT..." "MATCH FOUND AT INDEX 4..."
  - หากสำเร็จ: ตัวอักษรขึ้นว่า "ACCESS GRANTED. DECRYPTION COMPLETE." แล้วมีปุ่ม "NEXT MISSION" ปลดล็อคขึ้นมา
  - หากพลาด: บันทึก Error เป็นภาษาที่เข้าใจง่ายและตลก สไตล์ Cyber heist เช่น "⚠️ CODE OVERLOAD: Index out of range! คุณตกนอกขอบเขตความปลอดภัยเซิร์ฟเวอร์ รีบแก้ไขด่วนก่อนโดนจับ!"

สร้างเกมนี้ขึ้นมาในไฟล์เดียวแบบ Single html ที่รวบรวม CSS (Tailwind) และ JS ไว้ด้วยกัน เพื่อให้เล่นได้ทันที มุ่งเน้นการเขียน UI ให้ออกมาเป็น Retro Hacker cyber-aesthetic ที่น่าดึงดูด และกลไกเกมเพลย์ทุกด่านต้องสามารถตอบโต้ (Interactive) ได้จริง ไม่ใช่หน้าจอสมมติ (no placeholder/full game loop for 3 levels) เริ่มลุยได้เลย!






จากโค้ดเวอร์ชันล่าสุด ให้ทำการ Refactor โครงสร้างของเกมใหม่เพื่อเตรียมรองรับการเพิ่มด่านจำนวนมาก (Scalability) โดยทำตามนี้:

1. แยกข้อมูลภารกิจทั้งหมดออกเป็น Array of Objects (เช่น `const gameLevels = [...]`) โดยในแต่ละ Object ให้มีโครงสร้างมาตรฐาน เช่น:
   - id: เลขด่าน
   - title: ชื่อด่าน
   - briefing: เนื้อเรื่องและคำใบ้
   - rawData: ข้อมูลตั้งต้นที่ให้เด็กเห็น
   - initialCode: โค้ดเริ่มต้นใน Editor
   - expectedLogic: ฟังก์ชันหรือ RegEx ที่ใช้ตรวจคำตอบ
   - successMessage / failMessage
2. ปรับแก้ UI และ Game Loop ให้ดึงข้อมูลจาก `gameLevels` มาแสดงผลแบบ Dynamic (เมื่อผ่านด่านให้ `currentIndex++` แล้ว render ใหม่)
3. ทำให้แน่ใจว่าระบบตรวจสอบคำตอบ (Validation) สามารถอ่านค่าจาก Object และประมวลผลได้อย่างถูกต้อง โดยไม่ต้อง hardcode เงื่อนไขของแต่ละด่านไว้ในฟังก์ชันหลัก

ขอโค้ดที่อัปเดตระบบนี้ให้สมบูรณ์ โดยยังคงด่านที่มีอยู่เดิมไว้ก่อน









ทำหน้าที่เป็น Game Level Designer สร้างด่านใหม่สำหรับเกม Cyber Heist เพิ่มอีก 10 ด่าน ส่งมาเฉพาะส่วนของข้อมูล Array `gameLevels` เพื่อให้ฉันนำไปเสียบในโค้ดเดิมได้เลย

เป้าหมาย: สำหรับเด็กมัธยมอายุ 12-18 ปี  โดยผสมผสานหลักการคิดแนวคณิตศาสตร์แข่งขัน (Math Logic) และตรรกะการแก้ปัญหา (Murdle-style deduction) เข้ากับ Python พื้นฐาน 

ธีมของด่านให้ไล่ระดับความยากดังนี้:
1. หมวด Cryptography & Modulo (ด่าน 4-6): ใช้คณิตศาสตร์เรื่องเศษเหลือ (Modulo) และลำดับตัวเลข (Sequences) เช่น การเลื่อนตัวอักษรเพื่อถอดรหัส (Caesar Cipher แบบง่าย) หรือหาตัวเลขที่หายไปในชุดข้อมูล
2. หมวด Logic & Deduction (ด่าน 7-9): มีข้อมูล Log ที่ขัดแย้งกัน เด็กต้องเขียนเงื่อนไข If-Else ผสม And/Or เพื่อหาว่าใครคือหนอนบ่อนไส้จากข้อมูลตรรกะที่กำหนด 
3. หมวด Algorithmic Thinking (ด่าน 10-13): การค้นหาตัวเลขหรือข้อความที่ตรงตามเงื่อนไขทางคณิตศาสตร์แบบเฉพาะเจาะจง (เช่น หางานที่ใช้เวลาน้อยที่สุด, หาตัวเลขที่เป็นจำนวนเฉพาะใน Array)

รบกวนเขียนเนื้อเรื่อง (Briefing) ของแต่ละด่านให้เท่ สไตล์สืบสวนไซเบอร์ และเตรียม `rawData` กับเงื่อนไขการตรวจคำตอบมาให้พร้อม
